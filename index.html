GBD_SERVER field guide

Everything that is different on our world: the mods everyone runs, the server-wide rule changes, and the keys that do the new things.

Getting in

Install the GBD modpack

Install the manager

Thunderstore Mod Manager, game set to Valheim.

Get the modpack

In the manager: Online → search → Download. Or open its Thunderstore page. It installs every mod at the server's exact versions.

Start Modded

Launch from the profile the pack created, then join . The password is in Discord.

When Discord says "Server updated"

Installed → → Update. Just that one entry, not "Update all", which can pull versions newer than the server's.

Mod updates happen on their own: the server applies them only when nobody is on, checks that it starts cleanly, and posts to Discord. If a mod breaks after a Valheim patch, the server switches it off and Discord says which one. If you get refused on join, update the modpack.
